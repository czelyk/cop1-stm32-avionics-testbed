# Earlier software-only validation — scope

The original uploaded research archive (`ctc1_next_experiment_20261014.zip`) contains 64 reference simulator scenarios. Its final evidence audit lists 1,536 source/admission/commit/sink identities with exact bytes and order and no duplicates, with time modeled by **assigned virtual service costs**.

The software study reported that the detailed model had lower synthetic prediction error but did not change the buffer or feedback configuration selected by the simpler model. This is **not** a measurement of MCU latency or a demonstrated new spacecraft engineering result.

This public repository contains only a concise result summary and test adapters. Raw predictions, private research reports and full experiment campaigns are intentionally omitted. All statistics need to be attributed to the proper simulator/test envelope.
